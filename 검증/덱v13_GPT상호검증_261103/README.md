## 서로 바로잡은 것

- **Codex → Claude:** «제휴로 시작 → 기준 DB부터 자체 실험실 · 숫자는 거의 그대로»는 틀림 — 위탁 원가 43만 원으로는 25만 원 가격 불가, DB까지 위탁하면 약 9.1–9.4억, 자체 실험실이 DB에 꼭 필요하다는 근거도 없음 · «측정 빼면 판정만으로 회귀»는 과함 — 이승민 안은 시험 전 설계 · 측정 사양서까지 들어감
- **Codex → 재원 비판 원문:** TIPS는 대학 등 소속 예비창업팀이 법인 전 신청 가능(선정 뒤 설립) · 예비창업패키지 외 반례(창업중심대학) · 25% 자부담이 전부 현금은 아님 · 원료 국산화는 덱이 이미 «원료사 대상»이라 씀 · 예비창업패키지 2026 마감은 3/26(최종 수정 공고)
- **Codex → 팀원 사업성 재검증:** «6억은 TIPS 누적 상한»은 덱 비용 추계와 지원 한도를 섞은 것
- **Codex 자기 수정:** 1차의 1,583만 원(총 20명 × 3시점)은 최소 예시 → 덱 A5 기준 2,030만–2,480만 원(자체 단가)이 맞음
- **Codex → 이승민 안:** «재면 독립성을 잃음 · 제품 · 시험 쪽은 스스로 못 함»은 과함(돈을 받고 설계까지 한 쪽이 판정) — v13 본편에는 «독립 판정»을 쓰지 않음
