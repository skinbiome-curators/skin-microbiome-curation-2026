# 사업 분야 심사위원 사전 읽기 — 2조 (slides_v3, s00–s22)

읽는 사람: 스타트업 투자·사업개발. 미생물·피부·통계·데이터 처리 모름. 대회 취지 잘 모름. 10/10 피칭 못 봄.

## 장별 메모

### s00 표지
- 한 줄: 민감 피부 화장품의 '마이크로바이옴 시험'을 설계하고 판정해 주는 서비스를 하겠다.
- 막힘: '함정을 잡는 분석 기술'(무슨 함정?) / '판정'(무엇을 판정? 합격·불합격?) / '큐레이션 방향: 예방·관리', '아이디어 형태: 서비스→사업화' 태그(대회 분류인 듯하나 설명 없음) / '관문 설계'(관문이 뭔지 처음 등장, 설명 없음)
- 5초: 예 (제목은 들어옴. 다만 '마이크로바이옴 시험'이 무엇인지는 모름)

### s01 한눈에 보는 제안
- 한 줄: 문제(시험이 설계에서 망가짐) → 우리 기술(다섯 관문 + 설계 점검) → 제안(설계 점검 → CRO 시험 → 판정·문장).
- 막힘:
  - '시퀀싱 런'(모르는 용어. 왜 런이 다르면 효과 판단이 불가한지 모름)
  - '관문 ①②', '다섯 관문'(내부 용어. 다섯 개가 뭔지 이 장에 없음)
  - '코호트 11개'(모르는 용어)
  - 'Malassezia restricta 신호'(학명. 좋은 건지 나쁜 건지도 모름)
  - 'CRO'(약어 풀이 없음. 임상시험수탁기관으로 짐작만)
  - '바로 쓰는 문장'(광고 문구? 보고서 문장? 모름)
  - 각주 '07 = 수업 자료 중…'(본문에 07이 안 보임. 내부 번호)
- 5초: 반쯤. 세 칸 흐름은 보이나 '판정·바로 쓰는 문장'이 무엇을 파는지 안 들어옴.
- 사업 메모: '화장품 회사 88%가 10명 미만' → 시장이 영세하다는 근거로는 좋음. 그런데 영세 업체가 돈을 낼 수 있는지는 반대 근거도 됨.

### s02 10/10 이후 바뀐 점
- 한 줄: 지난 피칭 대비 고객·방향·결과물·시장·매출·비용을 이렇게 바꿨다(심사 피드백 반영).
- 막힘: '10/10 최종 피칭'(나는 못 봤음 → 비교 기준 없음) / '판정 엔진' / '원시 FASTQ'(모르는 용어) / 'BMI처럼'(피드백 인용인데 무슨 뜻인지 맥락 없음) / '채택·후속·조건부·보류' / '문장별 ✅△❌'
- 5초: 아니오. 7행×4열 표. 처음 보는 사람에겐 '이전 버전'이 없어서 2번째 장에 둘 이유가 약함.
- 사업 메모: 피드백을 받아 고객을 R&D 연구소 → 중소 브랜드로 바꾸고 반복 매출 고리를 넣었다는 점은 학습 능력으로 읽힘(좋음).

### s03 주제 선정 배경
- 한 줄: 사람 71%가 조금이라도 민감한데 객관적 판정 기준이 없다 / 시장에는 마이크로바이옴 표방 제품·CRO 시험이 이미 있다 → 피부 미생물이 객관적 지표가 될까?
- 막힘: '자통 시험'(모르는 용어) / '16S', '균 분류 프로파일'(모름) / 'CRO'(여전히 풀이 없음) / '기능성 보고'(식약처 제도인 듯, 짐작)
- 5초: 예. 71% 숫자와 하단 질문이 바로 들어옴.
- 사업 메모:
  - '연 20–30곳 · 누적 137곳'이 이 팀이 말하는 고객 풀로 보임 → 시장이 작다는 인상. 돈(금액) 단위가 없음.
  - 하단 QUESTION이 '진단 지표가 되나?'인데, 표지·s01은 '시험 설계·판정 서비스'. s02에서 '진단→예방·관리'로 바꿨다고 해 놓고 여기 질문은 여전히 진단 쪽 → 무엇을 파는지 다시 흔들림.

### s04 데이터셋
- 한 줄: 수업 자료 6편 + 외부 1개(총 7곳, 코호트 11개)를 목적별로 골라 썼고, 서로 합치지 않고 각각 안에서만 판정했다.
- 막힘:
  - '03 · 07 · 15 · 01·02·16'(설명 없는 내부 번호. 각주에 '수업 자료 번호'라고만 있음. s01 각주의 '07'이 이것이었다는 걸 여기서 알게 됨)
  - '7곳' vs '11개 코호트'(곳·편·코호트·자료가 섞여서 같은 것인지 다른 것인지 모름. 자료를 '곳'으로 세는 것도 어색)
  - '16S 1,308 · ITS 596', '세균+진균', 'EGA', '이식성', '음성대조', '면봉↔세척액', 'DNA 구간'
  - '④ 판별력'(④가 다음 장에서야 정의됨)
- 5초: 아니오. 숫자가 너무 많음(7·11·1,308·596·42·595·25·75·24·17…).
- 사업 메모: 대부분 '수업 자료'라는 게 눈에 띔. 대회 취지가 공개 자료 큐레이션이라면 당연하겠지만, 사업 관점에선 '실제 고객 데이터로 해 본 적은 없다'로 읽힘. 화장품 실제 시험은 25명 1건(07)뿐.

### s05 분석 기술 — 다섯 관문
- 한 줄: 데이터에 숨은 함정 5가지(오염·흔들림·이름 오류·우연·종 혼동)를 하나씩 거르는 검사 단계를 만들었고, 화장품 시험용 '설계 점검'을 새로 더했다.
- 막힘: 각 칸 본문 거의 전부 — '군도 0', '시약 유래 균', '검출률', '심도', '블랭크', '로그비', '분류 데이터베이스', '미분류 서열', 'BLAST', 'Mann–Whitney AUC', '4,000번 재표본', '정규분포', '속 안에 병원성·상재 종', '라벨'
- 좋았던 것: 관문 이름을 질문형('늘 잡히나 · 흔들리나 · 이름표 믿나 · 가르나 · 종까지 말하나')으로 한 건 비전문가도 '품질 검사 체크리스트구나'를 잡게 해 줌.
- 5초: 반. '5단계 검사'는 들어옴. 하지만 각 단계가 고객에게 무슨 사고를 막아 주는지는 안 들어옴(함정 설명이 기술 언어).
- 사업 메모: 이게 '기술 해자'인지, 누구나 할 수 있는 표준 절차 묶음인지 판단이 안 됨. 하단 AI 칸 '표준 통계 도구와 대조'는 오히려 '표준 도구로 되는 것'처럼 읽힘.

### s06 주요 결과 ① 후보 4개와 Malassezia 신호
- 한 줄: 1,000여 개 균 중 걸러서 후보 4개를 남겼고, 그중 Malassezia는 민감한 사람에게서 확연히 적다(중앙값 36% vs 84%, 구분 확률 85%). 나머지 3개는 42명으로는 아직 판단 불가.
- 막힘: '속'(분류 단위인 듯) / '상대풍부도' / 'AUC'(장 안에 쉬운 풀이가 있어서 오히려 이해됨) / '신뢰 구간이 50%에서 떨어져 있음' / '순환 방지' / 'ITS1 · 16S · 부트스트랩'(각주) / 학명 7개(Cutibacterium 등 — 이름만 봐선 좋은 균인지 나쁜 균인지 모름)
- 좋았던 것: '85% = 민감 1명·비민감 1명을 뽑으면 비민감 쪽이 더 많을 확률' — 비전문가용 번역이 장 안에 있음. 막대 두 개(84.2 vs 36.4)는 5초 안에 들어옴.
- 5초: 예(오른쪽). 왼쪽 '출발 → 질문 셋 → 후보 4 → 걸러짐' 흐름은 아니오.
- 사업 메모: 'Malassezia가 적다'가 고객(브랜드)에게 무슨 의미인지 없음. 늘려야 좋은 건지, 그냥 표시 지표인지 모름. 42명이라는 작은 표본을 스스로 '판단 불가'로 밝힌 건 신뢰 ↑.

### s07 주요 결과 ② 교란 점검과 종 수준
- 한 줄: 나이·피지·계산 방식 같은 다른 이유로 생긴 착시가 아님을 확인했고, 진균은 종(M. restricta)까지 내려갈 수 있지만 세균은 안 된다 → 다음 시험에서 M. restricta를 직접 재자.
- 막힘: '교란'(제목부터 모르는 말) / '로지스틱 회귀(표준화)', '판별력 AUC 0.65→0.88', '한 명씩 빼고 검증', '피지 AUC 0.49'(높은지 낮은지 기준 없음) / '로그비' / 'ρ = −0.98' / '절대량' / '리드', '우점종' / 'NCBI BLAST', '정렬 1-375', '틈 0', '375자' / 'S. aureus · S. epidermidis' / 'qPCR' / 각주의 파일명·'ASV0006'·'저장소 results/'(심사위원에게 무의미)
- 5초: 아니오. 이 덱에서 가장 빽빽한 장 중 하나. 하단 띠('우선 잴 후보 = M. restricta')만 남음.
- 사업 메모: '다른 이유 아닌가'를 스스로 점검하고 '검증 전 후보'라고 선을 그은 태도는 신뢰. 다만 오른쪽 BLAST 코드 박스는 사업 심사엔 과함.

### s08 주요 결과 ③ 공개 화장품 시험 재분석
- 한 줄: 실제로 공개된 화장품 인체 시험(25명·75시료)을 다시 보니, 사용 전(0주)과 후(4주) 시료를 서로 다른 실험 회차(런)에서 돌려서 '제품 효과'와 '실험 회차 차이'를 구분할 수 없다 → 원 논문의 '균이 늘었다'는 결론을 지금 설계로는 낼 수 없다.
- 막힘: '시퀀싱 런'(s01부터 계속 나오는데 끝까지 풀이 없음. 색 블록 덕에 '실험 묶음 번호' 정도로 짐작) / 'FASTQ 머리줄' / '6속', '분모에서 빼면' / 'Holm 보정 p 0.18·0.75' / '검출 문턱' / 각주 학명 6개
- 같은 것을 다른 말로: 제목 '결론 불가' · 판정 칸 '아직 안 됨' · 하단 '가를 수 없다' — 같은 판정을 세 가지로 부름.
- 5초: 예. 제목 옆 '결론 불가', 빨간 '아직 안 됨', 0주/4주 색이 다른 블록이 한 번에 들어옴.
- 사업 메모: 이 장이 '문제(고객의 고통)'를 가장 구체적으로 보여 줌 → 설득됨. 다만 사례가 1건. '이런 설계 실수가 업계에 얼마나 흔한가', '이 시험 한 번에 회사가 얼마를 썼나'가 없음.

### s09 검증 — 믿을 수 있는 이유
- 한 줄: 기준은 사람이 미리 정하고, 숫자는 별도 코드로 다시 계산하고, 검수 과정도 일부러 오류를 심어 시험했다.
- 막힘: '검수'(검토와 같은 말?) / '사후 규칙' / '시드 고정' / '10/31 독립 검토'(누가?) / '측정 전에 등록'(사전 등록 개념인 듯) / '15 계절 미국·중국 → 홍콩 · 74명'(무슨 오류인지 맥락 없음) / 'OTU → ASV'(모름) / 각주 'ENA PRJNA390040', 폴더 경로
- 5초: 예. 1·2·3 세 기둥 제목이 깔끔.
- 사업 메모: 서비스를 팔 때 '우리 판정을 왜 믿나'에 대한 답이 되는 장이라 좋음. 자기 실수(고친 오류)를 공개한 점도 신뢰 ↑. 다만 하단 '사람/AI' 띠가 s00·s05·s09 세 번 반복 — 대회 규정인지 모르겠지만 반복이 많음.

### s10 결과에서 얻은 세 가지
- 한 줄: ① 민감 피부엔 잴 후보(M. restricta)가 있다 ② 피부 미생물 시험은 설계에서 갈린다 → 시험 전 점검이 가장 큰 절약 ③ 이 함정은 피부 마이크로바이옴 시험 전반의 문제다 → 그래서 '지표'가 아니라 '시험 설계·판정'을 판다.
- 막힘: '해상도', '런 겹침', '관문 ①②③⑤'(번호만으로 다시 지칭) / 각주 '07 · 15 계절'(내부 번호)
- 5초: 예. 하단 띠 '지표를 파는 대신 — 시험을 한 번에 제대로 설계'가 이 덱의 핵심 문장으로 처음 확실히 들어옴.
- 사업 메모: '가장 큰 절약'의 금액이 없음. ③에서 시장을 '피부 마이크로바이옴 시험 전반'으로 넓혔는데 크기(건수·금액)가 없음. 그리고 '지표를 팔지 않는다'면 s06–s07 두 장을 쓴 Malassezia가 사업에서 어떤 역할인지 여기서야 정리됨 — 순서가 거꾸로 느껴짐.

### s11 큐레이션 방향 — 예방·관리
- 한 줄: 진단·예방관리·치료 중 '예방·관리'를 골랐다 — 민감 피부 관리 수단은 화장품이고, 회사가 실제로 돈을 쓰는 곳은 인체 시험이므로 그 시험을 설계·판정한다.
- 막힘: '큐레이션 방향'(대회가 정한 3택 틀인 듯하나 설명 없음) / '판정 엔진' / '07 재분석'(내부 번호)
- 중요한 정보가 각주에 숨어 있음: '하지 않는 것: 진단·효능 보증·시험 수행·법률 자문 — 판정 문서는 「이 데이터가 이 문장을 받치는가」만 말함'. 여기서 처음으로 s01의 '바로 쓰는 문장' = 제품 표시·광고 문구라는 걸 이해함. 시험은 직접 안 하고 CRO가 한다는 것도 여기서 확정.
- 5초: 예.
- 사업 메모: '중소 화장품사가 실제로 돈을 쓰는 곳은 인체 시험'이라는 주장에 숫자(건당 비용·연 지출) 근거가 없음.

### s12 서비스 개요 — 누구에게, 어떤 경로로
- 한 줄: 분석 체계 없는 중소 브랜드(설계부터)·중소 원료사(판정부터)를 고객으로, 피부 CRO와 협력해 팔고, 2순위로 EU·영국 수출 쪽, 첫 분야는 민감 피부 라인.
- 막힘: 'EU·영국 등록 기관 묶음'(무엇을 묶는다는 건지, 누구인지 모름) / '제11조 ②(d)'(법 조항 번호만) / '판정 입구 · 설계 입구'('입구'가 첫 구매 상품이라는 뜻인지 짐작) / '설계 요구서' / '16S 균 분류 프로파일' / 'PIF'(풀이는 있음) / 'PIF 서명'

- 한 것: 수업용 공개 피부 미생물 자료에 자체 '다섯 관문' 검사를 돌려 민감 피부에서 특정 진균(M. restricta)이 적다는 후보 신호(42명, 검증 전)를 찾았고, 실제 공개된 화장품 시험 1건을 다시 분석해 '사용 전·후 시료를 다른 실험 회차로 돌려 효과 판단이 불가능하다'는 설계 결함을 보이고 이를 견본 리포트·문장 카드로 만들었다(고객 접촉·유료 검증은 아직 없음).
- 확신도: '하려는 것'은 s10–s12까지 가서야 확실해짐. s00–s09는 '민감 피부 지표 연구'로 읽혔음.
