# 계획서 다섯

## 계획서 1
- 원하는 문장: ‘4주 사용 뒤 볼 피부의 Cutibacterium 비율이 무처리 대조보다 더 늘었다.’
- 대상 · 판매 시장: 건강한 한국 여성 20–49세 · 국내 판매
- 인원: 두 군 각 30명(표본 수 계산서 첨부)
- 배정: 무작위 1:1 · 평가자 눈가림
- 군: 제품 사용군 · 무처리군
- 시점: 사용 전 2회(−1주 · 0주) · 사용 4주
- 채취 부위: 왼쪽 볼의 표시한 같은 자리(모든 시점)
- 함께 쓰는 제품: 시험 2주 전부터 끝까지 같은 세안제를 나눠 주고, 다른 기초 화장품은 쓰지 않음
- 시료 처리: 면봉을 −80°C 에 보관했다가 시험이 끝난 뒤 처리. 실험실 일정상 제품 사용군 시료는 1차(추출 플레이트 1 · 시퀀싱 런 1), 무처리군 시료는 2차(추출 플레이트 2 · 시퀀싱 런 2)로 처리
- 대조 시료: 플레이트마다 음성 대조 · 런마다 모의 군집
- 분석: 16S rRNA V3–V4 비율 + 전체 세균 qPCR
- 사전 등록: 주 균 Cutibacterium · 방향 ‘증가’ · 주 시점 4주 · 두 군의 변화량을 직접 비교
