▶이 슬라이드는 이렇게

저희 질문은 피부 미생물로 민감피부를 구별할 수 있느냐였습니다.

결론부터 말씀드리면, 진균 Malassezia는 민감군에서 절반 이하로 낮고 나이를 넣어도 유지됩니다. 세균 셋은 42명으로는 판단할 수 없었습니다.

그래서 최종 결과물은 기업 R&D용 검증 설계서로 잡았습니다. 오늘은 여기까지 오는 동안 저희가 한 분석 선택들이 맞았는지를 여쭤보려 합니다.

※알아둘 것

  • AUC 0.153 — 0.5면 무작위. 0.153은 “민감군에서 적다” 쪽으로 강함 (1−0.153 = 0.847)
  • 나이를 넣어도 유지 — 나이 모형 위 증가분 +0.23 [0.07, 0.41], 교차검증 +0.27 (6장)
  • 원 논문 재현 — Malassezia 감소는 Keum 2020이 이미 보고. 저희 기여는 발견이 아니라 적격성 판정

자료 구조

?질문

  1. 라벨은 42명에만 있고 사용 조건은 595명으로 보는 두 자료 조합이 타당한가요?
  2. 채취 부위·시퀀싱 영역이 다른 자료를 이식성 확인에 쓰는 것, 괜찮을까요?

▶이 슬라이드는 이렇게

자료는 모두 공개 자료이고, 질환 코호트는 쓰지 않았습니다.

핵심은 민감 라벨이 42명에만 있다는 점입니다. 그래서 판별력은 42명으로만 보고, 595명은 검출이나 나이·피지와의 관계 같은 사용 조건을 보는 데 썼습니다.

나머지 코호트는 판정표를 다른 자료에 돌려 보는 이식성과, 반복 측정이 있는 자료로 시간 안정성을 보는 데 썼습니다. 채취와 영역이 달라서 값을 직접 비교하지 않고 각 자료 안에서만 판정했습니다.

※알아둘 것

  • 595명 — 새로 모은 자료가 아님. 공개 코호트(EGA EGAS00001007334, 원 연구 950·989명)에서 20–79세 여성으로 추린 재분석 집합
  • 42명 라벨 — 원 논문이 SLS 패치 + 유산 자통시험 + 설문 3종 모두 충족으로 정함. 우리 임상표엔 시험 수치가 없어 재현 불가
  • 595명 설문 라벨(Baumann) — 있지만 정답표로 못 씀: 붉은기와 무관(AUC 0.52), 나이(0.31)·피부 밝기(0.62)를 가려냄
  • 공개 자료 전수 조사 — 민감 라벨이 붙은 한국인 코호트는 42명 외에 없었음

▶이 슬라이드는 이렇게

원자료 25개에서 시작해 1번 코드가 분석표를 만들고, 나머지 코드 12개가 관문별로 계산해서 분석표 17개를 남기고, 그걸 모아 판정표 한 장을 만듭니다.

원칙은 네 가지입니다. 외부 라이브러리 없이 표준 라이브러리만 썼고, 부트스트랩 seed를 고정했고, 입력 파일을 해시로 고정했고, 문서 값을 베끼지 않고 원자료에서 독립 재계산해 불일치가 0건이었습니다.

※알아둘 것

  • 직접 구현한 것 — xlsx 파서, Spearman(t분포 p · 불완전 베타 함수), AUC, 부트스트랩, BH, ICC, 로지스틱+교차검증
  • 검증에서 스스로 찾은 오류 10건 — 예: 진균 ⑤를 “불가”로 적었다가 ASV 표로 정정 · Spearman p를 정규근사로 계산했다가 t분포로 교체(진균 오염 의심 3속→2속) · 블랭크 “미검출”을 “문턱 미만”으로 정정
  • 남은 약점 — 2_게이트_판정.py의 Spearman p는 아직 정규근사(ρ만 인용) · 표본 크기 계산은 코드로 안 남음
  • OS 이식성 — 한글 Windows에서 cp949 인코딩 오류로 3개가 죽던 것을 UTF-8·LF 고정으로 해결

▶이 슬라이드는 이렇게

관문은 통계 교과서가 아니라 마이크로바이옴 자료에만 있는 함정에서 출발했습니다.

비율 데이터는 로그비와 0 처리값 민감도로, 심도는 저심도 구간을 따로 봐서, 라벨 오류는 사례별로, 시약 오염은 심도 상관과 블랭크로, 채취 방법은 두 자료 배수 규칙으로 다뤘습니다.

오른쪽 칸이 각각 남은 한계입니다. 특히 정식 조성 모형과 음성대조가 없다는 게 큰 약점입니다.

※알아둘 것

  • ① 비율 데이터 — “몇 마리”가 아니라 “전체 중 %”라 합이 항상 100% · 파이 한 조각이 커지면 옆 조각이 작아지는 것 → 기준균으로 나눈 로그비로 재계산, 0 대신 더하는 작은 값(eps)을 100배 바꿔도 같은지 확인
  • ② 시퀀싱 심도 — 시료마다 DNA를 읽은 양이 달라 적게 읽으면 있는 균도 0 · 해상도 낮은 사진 → 하위 10%(4,714 read 미만, 59명)를 따로 떼서 검출률 비교
  • ③ 분류 라벨 오류 — DB 이름표가 틀림(Cutibacterium 칸에 물고기) · 속–종 불일치 212행(풍부도 1.2%) → 학명 개정 같은 정상 사례가 섞여 일괄 삭제 대신 하나씩 판단
  • ④ 시약 오염 — 키트·시약에 묻은 균 DNA가 결과에 섞임 → DNA 적은 시료일수록 비율이 커지는 균(심도와 반대로 움직임)을 의심 · 다른 연구 음성대조와 대조 · 우리 음성대조 없어 확정 불가
  • ⑤ 채취 방법 — 볼 면봉 vs 얼굴 세척액이면 균 구성이 크게 다름(Streptococcus 18.2% vs 0.6%) → 두 자료 5배 넘게 차이 나면 제외 · 단 채취법 차이와 실제 부위 차이는 구분 못 함
  • 발표 팁 — 오른쪽 “남은 한계” 칸이 핵심 · 한계를 먼저 말하고 “어떻게 보완하면 될까요?”로 넘기기 · 관문을 교과서가 아니라 자료의 함정에서 세웠다는 점이 중간발표 피드백(“연구방법 큐레이션 같다”)에 대한 답

판별력 측정

  1. n=42에서 AUC + 부트스트랩 신뢰구간이 적절한가요? 더 나은 방법이 있을까요?
  2. 표본 크기를 신뢰구간 폭 기준(±0.10)으로 잡은 게 맞나요? 검정력 기준이 나을까요?
  3. 다중비교 보정을 세균·진균 따로 한 것, 괜찮을까요?

▶이 슬라이드는 이렇게

판별력은 AUC로 쟀습니다. 민감 1명과 비민감 1명을 뽑았을 때 민감 쪽이 더 많을 확률입니다. 신뢰구간은 부트스트랩 4,000회로 냈고, 구간이 0.5를 걸치면 근거 부족으로 판정했습니다.

오른쪽 그림에서 세균 셋은 모두 점선 0.5를 걸칩니다. Malassezia만 확실히 왼쪽, 민감군에서 적은 쪽에 있습니다.

지금 신뢰구간 반폭이 ±0.18이라, 군당 65명이면 ±0.10까지 좁아진다고 계산했습니다.

※알아둘 것

  • AUC 방향 — 민감군이 더 많을 확률. 0.5 아래 = 민감군에서 적음
  • p값 — U의 정규근사 · 정확검정 대조는 두 값에서만 코드 밖으로 확인
  • BH 가족 — 세균 1차 통과 4속 + 탈락 공개 4속 = 8가설 · 진균 2가설 따로
  • 65명 계산 — Hanley–McNeil 근사 · 검증 때 손으로 확인, 코드로 안 남음 (알려진 약점)
  • 나이 자체 AUC 0.347 — 민감군이 젊어서 생기는 값 · 비교 기준으로 같이 표시

  1. 나이 보정을 로지스틱 + 한 명씩 빼는 교차검증으로 한 것, 충분한가요?
  2. 계산 방식에 따라 결과가 뒤집히는 Staphylococcus 같은 경우, 어느 표현을 믿어야 할까요?

▶이 슬라이드는 이렇게

결과를 흔드는 두 가지를 따로 점검했습니다.

나이 — 42명에서 민감군이 11살 젊어서 나이만으로도 어느 정도 갈립니다. 그래서 나이 모형에 후보를 더했을 때 오르는 몫을 쟀습니다. 세균 셋은 증가분 구간이 0을 걸치고, Malassezia만 +0.23으로 나이 위에 더합니다. 교차검증으로도 같은 방향입니다.

비율 — 595명 얼굴 세척액엔 구강균이 많아서 계산 방식을 세 가지로 바꿔 봤습니다. Cutibacterium은 견고하고, Staphylococcus는 부호가 뒤집히고, Corynebacterium은 사라집니다.

※알아둘 것

  • 교차검증을 한 이유 — 같은 42명으로 맞추고 재면 변수를 더할수록 AUC가 거의 항상 오름 → 한 명씩 빼고 다시 재서 그 편향을 걷어냄
  • 나이 모형 AUC — 재대입 0.653 · 교차검증 0.581
  • Staphylococcus — 로그비 쪽(−0.15)이 595명 원 논문의 “여성에서 나이와 함께 감소”와 맞음
  • 구강균 <20% 부분집합 — 구강 10속 합이 20% 미만인 218명만 따로 계산

  1. 음성대조 없이 심도 상관으로 오염을 보는 방식, 어디까지 믿을 수 있나요?
  2. 기준을 p가 아니라 ρ < −0.30으로 잡은 것, 적절한가요?
  3. 다른 연구의 블랭크로 대조한 것에 의미가 있을까요?

▶이 슬라이드는 이렇게

저희 자료엔 음성대조가 공개돼 있지 않아서, 시약에서 온 균은 DNA가 적은 시료일수록 비율이 커진다는 원리로 심도와의 상관을 봤습니다.

42명 세균에서 8속이 걸렸고, 후보 중엔 Corynebacterium이 두 자료 모두에서 같은 방향이라 「주의」로 뒀습니다.

같은 수업 자료의 다른 연구 블랭크 5개와 대조했더니 지목한 12속 중 6속이 블랭크 전부에서 나왔습니다. 다만 이건 대체 지표이고 오염을 확정하지는 못합니다.

※알아둘 것

  • 근거 논문 — Salter 2014: 순수배양을 10⁸→10³ 세포로 희석하니 가장 묽은 단계에서 오염이 결과를 지배 · 권고는 사후 상관이 아니라 사전 음성대조
  • Corynebacterium — 42명 ρ=−0.385(q=0.063, 유의 아님) · 595명 ρ=−0.118(q=0.0086) · Salter 키트 오염균 목록에도 있음 → 피부 상재균이자 오염균 후보
  • 블랭크 정정 이력 — 처음엔 “음성대조에서 미검출”로 적었다가, 블랭크 4개 모두에서 검출(평균 0.435%)·문턱 0.5% 미만이었음을 찾아 정정
  • 방법이 작동한다는 근거 — 걸린 Sphingomonas·Acinetobacter가 Salter 목록과 일치

후보 선정 규칙

  1. 결과를 본 뒤 정한 사후 규칙의 약점을 어떻게 보완하면 될까요?
  2. 채취법 차이와 실제 부위 차이를 가르려면 규칙을 어떻게 바꿔야 할까요?

▶이 슬라이드는 이렇게

807속에서 후보를 고른 규칙은 두 단계입니다. 1차는 흔한가, 2차는 두 자료 사이에서 5배 넘게 차이 나지 않는가입니다.

솔직히 말씀드리면 결과를 본 뒤 글로 정리한 사후 규칙입니다. 다만 규칙이 쓰는 값은 모두 민감/비민감 라벨과 무관하고, 문턱을 3배에서 20배 사이 어디에 둬도 같은 3속이 나옵니다.

약점도 있습니다. 비교 상대를 다른 건강 코호트로 바꾸면 Cutibacterium도 걸립니다. 규칙이 실제 부위 차이를 채취법 차이로 오인하는 겁니다.

※알아둘 것

  • Rothia — 42명 비교 p=0.024지만 8가설 보정 후 q=0.19 · 42명 검출률 59.5%라 1차 탈락 · 결과에 맞췄다면 남겼을 균
  • Lactobacillus — 42명에선 민감군↑(AUC 0.689, p=0.038)지만 595명 검출 63% · 배수 18배 · 오염 신호 → “유의한데 못 쓰는” 사례
  • 진균은 규칙이 다름 — 문턱 숫자는 같지만 595명에 진균이 없어 2차 미적용 → 세균보다 관문 하나 덜 거침
