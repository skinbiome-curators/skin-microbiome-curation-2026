## 0. 검증 규칙 — 이 문서의 전제

> **원문을 직접 열어 확인한 것만 "확인" 이다.**
> 검색 요약만 본 것은 **"못 찾음"** 으로 둔다. 출처가 있어도 마찬가지다.

이 규칙은 실패 경험에서 나왔다. 2026-09-18 초판에서 검색 요약만 보고 쓴 수치 두 개가 원문과 달랐다.

| 초판에 쓴 것 | 원문 | 차이 |
|---|---|---|
| *S. aureus* 정착률 **70% / 39%** | **62%(58/94) / 34%(32/94)** | 틀림 |
| *"차이는 **종 구성**에서 난다"* | 원문은 **조성도 유사**하다고 함 | **결론이 반대** |

두 번째가 특히 나빴다. **E4 사전등록 문구를 그 틀린 요약 위에 세울 뻔했다.**

## 1. *Cutibacterium* — ❌ 못 찾음

**원문 미확인.** 아래는 검색 요약에서 본 주장이며, **카드에 넣으면 안 된다.**
담당자가 원문으로 확인해야 하고, 확인 전까지는 §1이 빈칸이다.

| 확인해야 할 주장 | 왜 중요한가 |
|---|---|
| *C. acnes* **전체 상대풍부도**는 여드름에서 차이가 없거나 결과가 엇갈린다 | 통념(*"많으면 여드름"*)과 반대 |
| 신호는 **phylotype(strain) 수준 다양성**에 있다 | **16S 로는 못 보는 층위** |
| SLST 유형 A·C·F 증가 / H·K·L 감소 | 위 주장의 근거 |
| *C. granulosum* 도 차등 풍부 종으로 보고됨 | 우리 V1-V3 대표종이 *granulosum* |

**확인되면 카드 §1에 들어갈 문장 (초안):**
> *"16S 로는 phylotype 을 못 본다. 속은 물론 **종 수준으로도 '이 균이 많으면 여드름' 을 말할 수 없다.**"*

이 문장이 확인되면 **우리 판정의 상한**이 된다. 13차 §9(하지 않는 것)와 같은 경계다.

**후보 출처 (미확인):**

## 2. *Staphylococcus* — ✅ 확인

**출처:** Edslev SM 등, *Microorganisms* 2021;9(2):432 — [PMC7921937](https://pmc.ncbi.nlm.nih.gov/articles/PMC7921937/)
**확인 방법:** 원문 직접 조회 (2026-09-18)

### 2.1 연구 구성

| | 내용 |
|---|---|
| 대상 | **아토피 환자 94명 + 건강 대조 92명** |
| 기관 | Statens Serum Institut · Bispebjerg Hospital (코펜하겐) |
| 부위 | 병변·비병변 피부 (주로 **아래팔 안쪽 · 팔오금**) + **nares** |
| 영역 | **V3-V4** |
| 공개 | ENA **PRJEB42898** |

### 2.2 ⚠️ 이 논문이 우리 08_atopic 이다

| | 논문 | 우리 08 |
|---|---|---|
| 대상 수 | AD 94 + 건강 92 | Lesional **94** · Non-lesional **94** · Skin **92** |
| 영역 | V3-V4 | V3-V4 |
| 기관 | Statens Serum Institut | Statens Serum Institut |
| nares | 채취함 | Nose **186** (= 94+92) |

**일치한다.** 09/Feidenhansl 에 이어 **두 번째**다. §4에서 그 영향을 다룬다.

### 2.3 확인된 수치

| 항목 | 값 |
|---|---|
| *S. aureus* 정착 — **병변** | **62%** (58/94) |
| *S. aureus* 정착 — **비병변** | **34%** (32/94) |
| *S. aureus* **절대량** 병변 vs 비병변 | **1.8배** 증가 (adj. *p* = 0.002) |
| 세균 **총량 · alpha 다양성 · 조성** | **병변/비병변 유사** |

**중증도 상관 (Spearman ρ, adj. *p*):**

| 종 | 방향 | ρ |
|---|---|---|
| *S. aureus* | **증가** | 0.6 (병변) · 0.5 (비병변), *p* < 0.0001 |
| *S. capitis* | 증가 | 0.3 (비병변), *p* = 0.03 |
| *S. lugdunensis* | 증가 | 0.2 (비병변), *p* = 0.04 |
| ***S. hominis*** | **감소** | **−0.3** (비병변), *p* = 0.02 |

### 2.4 카드 §1에 넣을 문장

> *"아토피에서 *S. aureus* 는 병변 62% · 비병변 34% 로 정착률이 갈리고, 절대량은 병변에서 1.8배 높다(adj p=0.002). 중증도와는 *S. aureus* 가 양(ρ=0.6), ***S. hominis* 가 음(ρ=−0.3)** 으로 **방향이 반대**다. 속 수준 한 숫자로는 이 방향을 담을 수 없다."*
> — Edslev et al. 2021, *Microorganisms* 9(2):432

## 4. 문헌 확인이 데이터 쪽에서 터뜨린 문제 둘

§2 를 확인하는 과정에서 나왔다. **둘 다 문헌 문제가 아니라 우리 데이터 문제다.**

### 4.1 E4 는 독립 검증이 아니라 재분석이다

08 이 Edslev 2021 의 데이터이므로:

- E4 가 *"독립 데이터에서 확인했다"* 가 **될 수 없다**
- 그 논문이 이미 답했다 — *S. aureus* 절대량 병변 1.8배
- **우리가 더할 수 있는 것**: 그들은 *S. aureus* **절대량**·종 수준을 봤고, 우리는 **속 수준 상대풍부도**를 본다. 다른 층위다
- **예상**: 논문이 *"조성은 병변/비병변 유사"* 라 했으므로 **속 수준 상대풍부도 null 가능성이 높다**

> **사전등록 동결 전에 적을 것:** *"속 수준 null 은 종 수준 차이를 배제하지 않는다. 원 논문(Edslev 2021)은 같은 자료에서 S. aureus 절대량 1.8배 증가를 보고했다."*
> 결과를 본 뒤 적으면 사후 변명이 된다.

### 4.2 08 의 "Nose" 는 얼굴 피부가 아니다

논문 확인: nares 는 ***S. aureus* 배양 확인용**으로 따로 채취했고, 피부 마이크로바이옴 상세 분석 대상이 아니었다. **콧구멍 안(anterior nares)** 이다.

그런데 우리 `FACE` 필터가 `'nose'` 를 잡아 **얼굴 14층에 들어가 있고, n=186 으로 가장 큰 층이다.**

| | 현재(14층) | 비강 제외(13층) |
|---|---:|---:|
| *Cutibacterium* V3-V4 풍부중앙 | 32.79% | **50.86%** |
| *Cutibacterium* 전체 혼합 | 33.69% | 40.33% |
| *Corynebacterium* V3-V4 풍부중앙 | 2.64% | 1.88% |

그리고 *Corynebacterium* V3-V4 대표종이 ***accolens* 24.1%** 인데 **C. accolens 는 비강 상재균**이다(§3, 미확인). **그 값이 코 안에서 왔을 가능성이 크다.**

**주의:** 위 비교 실행은 층 구성만 고쳤고 **종 집계 함수는 안 고쳤다.** 종 수치는 아직 옛 값이다. 다음 세션에서 제대로 고쳐야 한다.
