## 1. 우리 방법의 근거 — 확인됨

> **오염 상대풍부도는 시료의 생물량과 반비례한다.**

희석 실험이 이를 보인다 — *Salmonella bongori* 순수배양을 10⁸ → 10³ 세포로 10배씩 희석했더니,
**가장 묽은 단계에서 "오염이 시퀀싱 결과를 지배"** 했다. qPCR 상 배경 DNA 는 약 500 copies/μL 에서 평탄해진다.
서로 다른 **세 실험실**에서 같은 종류 키트로 같은 패턴이 나왔고, **PCR 없는 샷건 메타지노믹스에서도** 확인됐다.

**이것이 우리 오염 판별법의 논리다**(관문 번호가 아니라 ① 안에서 쓰는 방법이다) — 시퀀싱 심도가 낮은 시료일수록 오염 비율이 높아지므로,
**심도와 강한 음의 상관**을 보이는 속을 의심한다.

## 2. ⚠️ 그러나 이 논문은 우리 방법을 권하지 않는다 — **정정 필요**

> 저자들이 권하는 것은 **사전 음성대조**다. *"음성대조 시료의 동시 시퀀싱을 강력히 권고한다."*
> 어떤 시료가 어떤 키트로 처리됐는지 기록해 **키트 로트 단위로 추적**하라고도 한다.
>
> **상대풍부도 대 생물량 상관으로 사후에 오염을 가려내라는 권고는 이 논문에 없다.**

### 그래서 우리 README 문장을 고쳐야 한다

| | |
|---|---|
| 지금 쓴 것 | *"심도-상관은 우리 자료 안에서 직접 재는 방법이라 **그 한계가 없다**"* |
| 고칠 것 | *"음성대조가 공개돼 있지 않아 **대체 지표**로 쓴다. 이 논문이 권하는 것은 **사전 음성대조**이고, 심도-상관은 그것을 대신하는 **차선책**이다."* |

**우리 `6_오염점검.py` 의 주석은 이미 정확하다** — *"음성대조 시료가 공개돼 있지 않으므로 이 상관을 대체 지표로
쓴다. 오염을 확정하는 검사가 아니라 의심 신호를 찾는 검사다."* README 쪽 표현만 과했다.

## 3. ⚠️ ***Corynebacterium* 이 알려진 키트 오염균 목록에 있다**

논문이 나열한 키트 오염 속에 우리와 겹치는 것이 많다.

| 논문 목록 | 우리 42명 의심 목록 | 우리 후보 |
|---|---|---|
| *Sphingomonas* | ✅ ρ=−0.579 | |
| *Acinetobacter* | ✅ ρ=−0.504 | |
| *Pseudomonas* · *Ralstonia* · *Burkholderia* · *Stenotrophomonas* 등 | | |
| ***Corynebacterium*** | | ⚠️ **후보 3속 중 하나** (ρ=−0.385) |
| *Propionibacterium*(= *Cutibacterium* 구명) · *Streptococcus* | | ⚠️ 후보·1위 탈락속 |

**우리 심도-상관이 독립적으로 *Sphingomonas*·*Acinetobacter* 를 잡아낸 것은 방법이 작동한다는 증거다.**

그리고 ***Corynebacterium* 의 「주의」 판정이 문헌으로 보강된다** —
우리 자료에서 심도와 음의 상관(42명 ρ=−0.385 · 595 ρ=−0.118)을 보이고, **알려진 키트 오염 속이기도 하다.**

> **다만 반대 방향으로도 읽어야 한다.** *Corynebacterium* 은 **피부 상재균이면서 동시에 키트 오염균**이다.
> 둘을 구별하려면 **음성대조가 있어야** 하고, 우리에겐 없다. 그래서 판정이 *"제외"* 가 아니라 **"주의 — 최소 read 조건 필요"** 인 것이 맞다.

*Propionibacterium*(= *Cutibacterium* 의 옛 속명)도 목록에 있으나, 우리 자료에서 *Cutibacterium* 의 심도 상관은
**양(+0.212 / +0.161)** 이라 오염 패턴과 **반대**다. 즉 오염 신호가 없다.

## 4. 논문이 준 추가 판별 기준 — 우리 의심 목록과 맞는가

> 저자들: *"생물학적으로 예상 밖인 분류군을 보라"* — 예컨대 **토양·수계 세균**이 사람 시료에서 나오는 경우.

| 우리 의심 속 | 알려진 서식 | 얼굴 피부에서 예상되나 |
|---|---|---|
| *Acidocella* (ρ=−0.751) | 산성 환경·광산 배수 | ❌ |
| *Mycobacterium* (−0.713) | 토양·수계 | ❌ |
| *Altererythrobacter* (−0.702) | 해양 | ❌ |
| *Rhodanobacter* (−0.678) | 토양 | ❌ |
| *Sphingomonas* (−0.579) | 토양·수계 · **논문 목록** | ❌ |
| *Acinetobacter* (−0.504) | 토양·수계 · **논문 목록** | 🔶 피부에도 있음 |
| *Veillonella* (−0.477) · *Neisseria* (−0.465) | **구강** | 🔶 얼굴 오염 가능 |

**두 기준(심도 상관 + 생물학적 예상 밖)이 대체로 일치한다.** 우리 목록이 무작위가 아니라는 근거다.
