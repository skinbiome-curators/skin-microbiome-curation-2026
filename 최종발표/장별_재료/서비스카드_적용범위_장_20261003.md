# A3. 서비스 화면 카드 — 세 장

HTML 덱에서 카드 UI로 그린다. 아래는 **내용 구성**이다. 판정 카드의 값은 `../README.md` «결과 요약» 판정표 그대로이고, **감시 리포트 카드는 2단계 측정 자료가 없으므로 값을 넣지 않는다**(지어낸 값 금지).

## 카드 ① 판정 카드 — 후보 한 균 = 한 장 (1단계 출력)

**예 1 · 신호가 있는 후보**
```
┌──────────────────────────────────────────────────────┐
│  Malassezia (진균)              다음에 할 일: 후속 패널 검증 우선 │
├──────────────────────────────────────────────────────┤
│ ① 검출 안정성   ● 통과        ITS 4코호트 596시료 · 검출 100%    │
│ ② 교란 취약성   ● 통과        나이 · 조성 모두                  │
│ ③ 분류 신뢰성   ◐ 주의        595명에 진균 자료 없음            │
│ ④ 판별력        ● 근거 있음   AUC 0.153 · q=0.0003 (42명)      │
│ ⑤ 방향성        ◐ 부분 가능   진균 한정 — M. restricta          │
│ ⑥ 반복측정(참고) ○ 불안정      ICC 0.195                        │
├──────────────────────────────────────────────────────┤
│ ⚠ 진균 다양성과 분리되지 않음(ρ=−0.979) → 절대량 필요          │
│ ▶ 패널: 주 지표 M. restricta + 전체 진균량                     │
└──────────────────────────────────────────────────────┘
```

**예 2 · 조건부 후보** — 신호가 없는 균도 같은 형식으로 보여 준다는 것이 요점
```
┌──────────────────────────────────────────────────────┐
│  Staphylococcus (세균)          다음에 할 일: 조건부            │
├──────────────────────────────────────────────────────┤
│ ① 검출 안정성   ● 통과        99.3%                           │
│ ② 교란 취약성   ◐ 표현 의존   계산 방식에 따라 부호가 뒤집힘     │
│ ③ 분류 신뢰성   ● 통과                                         │
│ ④ 판별력        ○ 근거 부족   AUC 0.449 [0.27–0.63] (42명)     │
│ ⑤ 방향성        ○ 불가        99.2% 종 미분류                   │
│ ⑥ 반복측정(참고) ○ 불안정      ICC 0.102                        │
├──────────────────────────────────────────────────────┤
│ ⚠ 16S로는 S. aureus · S. epidermidis 를 가르지 못함(BLAST 동률) │
│ ▶ 패널: 보조 — 종 특이 표적(tuf2 또는 gap · atlE)으로 다시 본다   │
└──────────────────────────────────────────────────────┘
```

## 카드 ② 패널 구성 카드 — 고객 한 곳 = 한 장 (1단계 출력)

```
┌──────────────────────────────────────────────────────┐
│  패널 구성안 — 기본안                                           │
├───────────────┬──────────────────────────────────────┤
│ ✅ 넣는 것      │ M. restricta (주 지표)                         │
│               │ S. aureus · S. epidermidis (보조)              │
│               │ C. acnes (보조 · 선택)                          │
│               │ 전체 진균량 · 전체 세균량 (절대량)                 │
│               │ 음성대조 — 채취 대조 4개당 1개                   │
├───────────────┼──────────────────────────────────────┤
│ ❌ 빼는 것      │ Corynebacterium — 피부 시료에서 검증된 종 표적 없음 │
│               │ 구강균(Streptococcus · Rothia) — 채취법이 만든 숫자 │
│               │ Lactobacillus — 세 겹 탈락                       │
│ ⏸ 보류         │ Rhodotorula 등 — 오염 의심, 다른 연구는 민감군 증가  │
├───────────────┼──────────────────────────────────────┤
│ 측정비(어림)    │ 시료당 $87–$178  (전체 시퀀싱 $184–$378)          │
│ 먼저 확인할 것   │ 범진균 qPCR의 Malassezia 증폭 · 피부 증폭 성공률   │
└───────────────┴──────────────────────────────────────┘
```
근거: `서비스_흐름_리포트_패널규칙_20261003.md` C3 · `패널근거_장_20261003.md` · `간이견적_20261003.md` O1 · O3

## 카드 ③ 감시 리포트 카드 — 측정 한 회차 = 한 장 (2단계 출력) · 형식 예시

```
┌──────────────────────────────────────────────────────┐
│  감시 리포트 — 회차 [  ]   채취일 [  ]   부위: 오른쪽 볼          │
├──────────────────────────────────────────────────────┤
│ 품질     시료 [  ]건 · 음성대조 [  ]건 → [통과 / 주의]            │
│ 주 지표  M. restricta 절대량 [  ]   전체 진균량 [  ]             │
│         비율(M. restricta ÷ 전체 진균) [  ]                     │
│ 해석     아래 규칙표로 자동 분류                                 │
│ 반복     같은 사람 이전 회차와의 일치도 [  ]                       │
│ 예외     표적 밖 신호 의심 → [다음 회차 전체 시퀀싱 권고]            │
├──────────────────────────────────────────────────────┤
│ 진단이 아닙니다 — 지표 후보 검증용 R&D 리포트                     │
└──────────────────────────────────────────────────────┘
```
> ⚠️ **값이 비어 있는 형식 예시**다. 2단계 측정은 아직 하지 않았다 — 발표에서도 "형식 예시"라고 말한다.

**해석 규칙표** — 이 카드가 쟁점 ①(패널도 비율)을 푸는 방법

| *M. restricta* 절대량 | 전체 진균량 | 비율 | 해석 |
|:-:|:-:|:-:|---|
| ↓ | 그대로 | ↓ | **실제 감소** — *M. restricta* 가 줄었다 |
| 그대로 | ↑ | ↓ | **비율 착시** — 다른 진균이 늘어 비율만 줄었다 |
| ↓ | ↓ | 그대로 | **전체 감소** — 채취량·DNA 회수 문제일 수 있음 → 품질 먼저 확인 |
| ↑ | ↑ | 그대로 | 전체 증가 — 같은 이유로 품질 확인 |

→ 우리 42명 자료에서 「*Malassezia* 감소 vs 진균 다양성 증가」를 **못 가른 이유(ρ=−0.979)**가 바로 이 표의 첫 두 줄을 구분할 절대량이 없었기 때문이다.

|---|---|
| 16S **V3–V4** | 595명(AAML) · 02건강(이마 · 볼) · 07화장품(볼) |
| 16S **V4–V5** | 42명(03 민감) |
| 16S **V4** | 15계절(이마) |

→ 코호트 **11개**(세균 7 · 진균 4) · ①과 ②(심도)는 **11/11**에서 판정 · ②(나이)는 나이가 기재된 세균 **5/7** · ④는 라벨이 있는 03뿐 · ③⑤는 속 요약표 기준 **0/11**(ASV를 쓰면 진균 ⑤ 부분 가능)

## 2. 입력이 판정 범위를 정한다

| 고객 자료에 있으면 | 판정할 수 있는 것 |
|---|---|
| 속 상대풍부도 표 + 시료별 read 심도 | ① 검출 안정성 · ②(심도) |
| + 나이 · 피지 | ② 교란 |
| + 민감/비민감 라벨 | ④ 판별력 |
| + ASV 표 | ③ 분류 신뢰성 · ⑤ 방향성(종 수준) |
| + 같은 사람 반복측정 | ⑥ 참고값 |
| + 음성대조 | 오염 점검 보강 |

## 3. 한계 — 먼저 말한다

| 한계 | 내용 | 근거 |
|---|---|---|
| 대상 | 판별력(④)은 **한국인 여성 42명** · 사용 조건은 한국인 여성 595명 · **남성·다른 인종에 적용 안 됨** | README «주의 사항» |

## 4. 확장 방향 — 무엇을 더하면 무엇이 풀리나

중간발표 20장 「확장 방향」의 네 갈래를 잇고, 멘토링에서 나온 것을 더한다.

| # | 확장 | 풀리는 것 | 출처 |
|:-:|---|---|---|
| ① | ASV 표로 다시 재기 | 세균 ③⑤ (진균 ⑤는 이미 부분 가능) | 중간발표 20장 |
| ② | 표본 군당 65명 | ④ 판별력 「근거 부족」 → 판정 | 같은 곳 |
| ③ | 절대량 + 반복측정 | *Malassezia* 축과 다양성 분리 · ⑥을 관문으로 | 같은 곳 · 카드 ③ 규칙표 |
| ④ | 대상 확장 — 남성 · 연령 · 부위 | 적용 범위 | 같은 곳 |
| 🆕 ⑤ | **입력 확장** — 롱리드 16S · ITS2 · 전체 시퀀싱 · 범용 입력 처리(C2) | 2회차 — 우리 42명·595명 조건에만 작동한다는 지적 | 2회차 [21:47] 「롱리드 … 지금 현재 트렌드」 |

## 6. 예상 질문

**Q1. 고객이 롱리드 자료를 가져오면?** — 아직 돌려 보지 않았다. 확장 ⑤로 계획에 있다. 「된다」고 말하지 말 것.
**Q2. 라벨이 없는 고객 자료는?** — ①②는 판정되고 ④는 「판정 불가」로 나온다(C1 리포트 예시가 그 모습). 그 자체가 고객에게 「라벨을 모아야 한다」는 정보다.
**Q3. 남성 피부에도 쓰나?** — 판정에 쓴 자료가 전원 여성이라 말할 수 없다.
