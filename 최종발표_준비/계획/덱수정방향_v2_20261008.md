## 5. 질의응답에서 즉답할 것

| 질문 | 답 | 근거 |
|---|---|---|
| q=0.0003은 몇 개 중에서 보정했나? | 진균 1차 통과 2속 안. 검출 진균 234속 전체로 넓혀도 q=0.03 | v4 §2-3 |
| ρ=−0.979면 다양성 지표 아닌가? | 우점균이 줄면 다양성이 오르는 수학적 관계가 큼 → 비율로는 못 가르고 **절대량**이 필요하다는 뜻 | 검D2 |
| 랜덤포레스트 +0.30이 더 큰 효과인가? | 아니다. RF의 「나이만」 기준선(0.51)이 낮아 커 보임. 「방법을 바꿔도 *Malassezia*만 보탰다」까지만 | 검D3 |
| 한 명씩 빼고 검증한 값은? | 0.581 → 0.847(MLE). 「나이만」 0.581은 이 방식에서 낮게 치우침 — 짝 빼기 교차검증으로는 0.653 → 0.874 | v4 §2-3, 검D4 |
| 왜 Mann–Whitney? 정규성은? | 목표 지표가 AUC = U ÷ (두 군 인원의 곱). 분포가 쏠려 있고 8개 중 7개 정규성 기각. *Malassezia* 민감군만 기각 안 됨(p=0.12) | v4 §6-4 |
| 블랭크에도 *Malassezia*가 있는데 오염 아닌가? | 다른 연구의 블랭크 1개라 참고값. 우리 자료엔 음성대조가 없어 오염을 배제하지 못함 → 2단계는 모든 단계에 음성대조 | 재검 3 |
| *Corynebacterium*은 왜 뺐나? | (D7 결정 후) 효과가 없는 게 아니라 42명으로 판단 불가 + 피부 군집 시료의 종 표적 선례를 찾지 못함. 검출 90% 문턱도 2명 차이로 넘음 | 검D5, A9 |
| 595명은 어디서? | AAML(mSystems 2026)과 같은 기준의 20–79세 여성 595명. 저자 공개 자료로 재분석, EGA 원시자료는 승인제 | 검A5 |
| *M. restricta* 절대량은 어떻게? | 종 특이 qPCR로 직접 정량(D2) — 파일럿에서 확정. 패널 비율 × 전체 진균량만으로는 자동으로 나오지 않음 | 재검 1 |
| 74명이면 충분한가? | 단일 지표 AUC 검정 기준의 예비 산정. 나이·피지 보정 증가분과 반복측정은 파일럿 뒤 확정 | 재검 2 |
| 01 노화 자료에선 *Malassezia*가 나이에 흔들리지 않나? | 01에서는 나이가 많을수록 낮음(ρ −0.665). 03에선 민감군이 11살 젊은데도 적어서, 나이 교란과 **반대 방향** | `판정표_이식성.json` |
| 경쟁사도 종 수준을 한다는데? | 종 수준을 **표방**하는 곳(HelloBiome · RUDDI)도 균별 기준값은 공개하지 않음. 차별점은 측정 해상도가 아니라 **지표 적격성 판정** | 웹 |
| 중간발표 뒤 무엇이 바뀌었나? | 9/12엔 4코호트 근거 가이드 → 「연구방법 큐레이션 같다」 지적 → 9/18 판정표로 전환 → 멘토링(9/29) → 2단계 서비스 | v4 §4 |
