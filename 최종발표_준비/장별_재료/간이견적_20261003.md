## 2. 단가표가 말해 주는 것 — ⚠️ 앞선 주장 하나를 고친다

- **표적 방식끼리는 차이가 작다.** 추출을 빼면 16S·ITS 앰플리콘 한 표적이 **$21–$36**(UNH · UConn), qPCR 한 표적이 **$15–$39**(Albany · 시카고대)로 겹친다.
- **큰 차이는 전체 시퀀싱 대비다.** 전체 시퀀싱은 **$184–$556**이다.
- **패널은 표적이 늘 때마다 붙는다.** UNH 구조로는 표적 하나에 PCR $10이 더해진다. 한 라이브러리로 묶으면(다중) 앰플리콘 한 번과 비슷한 단가가 된다(Case Western의 「custom amplicon」이 16S·ITS와 같은 값).
- 🔧 **정정** — 10/2 `시장경쟁_가격_재료_20261002.md` 장 C의 「표적 qPCR은 16S 앰플리콘의 약 **0.28배**」는 **시카고대 DFI 한 기관**의 비율이다($39 / $139). 다른 기관에서는 qPCR과 앰플리콘 단가가 비슷하다. → 「표적 측정이 싸다」는 **전체 시퀀싱 대비**로만 말한다.

→ **패널의 진짜 이점은 「앰플리콘보다 싸다」가 아니라 두 가지다.**
1. **종을 가른다** — 16S로 BLAST 동률이라 못 가른 *S. aureus* 와 *S. epidermidis* 같은 경우
2. **필요한 것만 잰다** — 판정표가 표적을 줄여 준다

**비용 이점은 「전체 시퀀싱 대신」**에서 크다.

## 3. 시나리오

### 3-1. 1단계 · 판정 1건

| | |
|---|---|
| 측정비 | **$0** — 고객이 이미 가진 시퀀싱 자료를 받는다 |
| 분석 작업량(추정) | 입력 형식 확인·정리 2–4시간 + 5관문 실행 1시간 미만 + 리포트 2–3시간 ≈ **5–8시간** — ⚠️ 우리 작업 경험에서 잡은 **추정**, 근거 문서 없음 |
| 가격 | 작업 시간 × 시간당 단가 — **단가는 팀이 정한다**(근거 없는 숫자를 넣지 않는다) |

### 3-2. 2단계 · 패널 감시 — 검증 규모(130명 · 2회 측정)

**가정** 군당 65명(총 130명) · 1인당 **2회**(반복측정 ICC) · 음성대조 **4개당 1개**(Fierer 2025) → 측정 건수 = 130 × 2 = 260 + 대조 65 = **325건**
> 🔧 10/3 C4 결과 — 피부 증폭 실패(약 23%)까지 반영해 AUC 0.65를 80% 검정력으로 잡으려면 **군당 74명(총 148명)** 모집이 필요하다(`추가분석/C4C5_결과_20261003.md`). 그 경우 아래 합계는 약 **1.14배**(148/130)가 된다.

| 방식 | 시료당 범위 | 계산(낮음 / 높음) | **325건 합계** | 한 번 드는 비용 |
|---|---|---|---:|---|
| **O1 얕은 전체 시퀀싱** | $184–$378 | 시카고대 내부 / 상업(추출 포함) | **$59,800 – $122,850** | — |
| **O2 16S + ITS 앰플리콘**(따로 2번) | $63–$278 | 낮음: 추출 $21 + UNH $21 × 2 / 높음: 시카고대 상업 $139 × 2(🔸 ITS = 16S 단가 가정) | **$20,475 – $90,350** | — |
| **O3 패널 4표적 + 전체 진균량 qPCR** ★ 우리 서비스안 | $87–$178 | 낮음: 추출 $21 + PCR $10 × 4 + 인덱싱 $10 + 시퀀싱 $1 = $72, + qPCR $15 / 높음: 한 라이브러리 $139(🔸 다중 패널을 한 라이브러리로 가정) + qPCR $39 | **$28,275 – $57,850** | qPCR 최적화 $950–$1,250 + 패널 분석 설정 $200 × 4 = $800 → **$1,750–$2,050** |
| **O4 qPCR만 2표적**(*M. restricta* + 전체 진균) | $51–$118 | 낮음: 추출 $21 + $15 × 2 / 높음: 추출 $40 + $39 × 2 | **$16,575 – $38,350** | 최적화 2건 **$1,900–$2,500** |

- 패널 4표적 = *M. restricta* · *C. acnes* · *S. epidermidis* · *S. aureus*(종 특이 선례가 있는 넷 — Wang 2023 표 2). *Corynebacterium* 은 선례를 못 찾아 넣지 않았다.
- O3에 전체 진균량 qPCR을 붙인 이유: 패널도 **비율** 자료라 절대량이 따로 필요하다(계획 쟁점 ①). ⚠️ 범진균 qPCR이 *Malassezia* 를 증폭하는지는 미확인(FungiQuant 원문에 *Malassezia* 없음)

**읽는 법**
- **O3(패널 + 절대량)은 O1(전체 시퀀싱)의 약 절반 이하**이고, O2(앰플리콘 두 번)와는 범위가 **겹친다** → "앰플리콘보다 싸다"가 아니라 **"전체 시퀀싱보다 싸고, 종을 가르며, 절대량까지 잰다"**
- **O4(qPCR만)가 가장 싸지만** 표적 밖은 보지 못한다(2회차 멘토 「미지의 시료 … 예외」) → 서비스에서는 O3를 주로, O4는 감시를 더 줄일 때의 선택지
- 범위 폭이 2–4배다 — **기관·요금 등급(내부/외부/상업)**에 따라 크게 달라진다는 것 자체가 결과다

### 3-4. 🆕 2026-10-09 팀 결정 D2 · D3 반영 재계산 — 덱 v4 18장에 쓸 값

**왜 다시 계산하나:** 10/9 팀 결정(`../계획/최종덱계획_v4_261009.md` §3) — D2 *M. restricta* 는 **종 특이 qPCR로 직접 정량**(패널 비율 × 전체 진균량으로는 절대량이 자동으로 나오지 않음) · D3 **전체 세균량 넣기** · D5 *C. acnes* 보조 · 선택. O3 는 「패널 4표적 + 전체 진균량 qPCR」이라 이 설계와 맞지 않는다.

**새 서비스안(O3′) = 세균 종 특이 패널 3표적(*S. aureus* · *S. epidermidis* · *C. acnes*) + qPCR 3종(*M. restricta* · 전체 진균 · 전체 세균)** — 단가는 §1 표 그대로, 방법은 §3-2 O3 와 같다.

|---|---|---|
| O1 얕은 전체 시퀀싱 | $184–$378 | §3-2 그대로 |
| O2 16S + ITS 앰플리콘 | $63–$278 | §3-2 그대로 |
| **O3′ 세균 패널 3표적 + qPCR 3종** ★ | **$107–$256** | 낮음: 추출 $21 + PCR $10 × 3 + 인덱싱 $10 + 시퀀싱 $1 = $62, + qPCR $15 × 3 = $45 / 높음: 한 라이브러리 $139 + qPCR $39 × 3 = $117 |

- **한 번 드는 비용:** qPCR 분석법 최적화 3건 $2,850–$3,750(Albany $950–$1,250 × 3) + 패널 분석 설정 $600($200 × 3)

- ⚠️ **추가 가정:** qPCR 단가는 표적 종류와 무관한 시료당 공개 요금(Albany 학술 SYBR $15 · TaqMan $20 · 시카고대 16S qPCR $21–$39)으로 잡았다. ***M. restricta* 종 특이 qPCR · 범진균 qPCR 의 실제 단가는 확인하지 못했다.** 높음은 다중 패널을 한 라이브러리로 묶는 가정 · 시카고대 DFI 는 2026-08-11부터 새 의뢰를 받지 않는다.
