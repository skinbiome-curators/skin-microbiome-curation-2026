# 민감피부 판별 패널 후보균 판정 → 패널 시퀀싱 분석 서비스

**피부 마이크로바이옴 큐레이션** · 동의대학교 바이오헬스 혁신융합대학사업단 2조 · 2026

> **In English** — Can common skin microbes serve as markers in a panel that tells sensitive skin apart?
> We screened four candidate genera through five gates — detection, confounding, taxonomic reliability, discriminative power and species-level direction — using public 16S data from 595 Korean women and 16S/ITS data from a 42-person cohort labelled sensitive / non-sensitive.
> The three bacterial genera (*Cutibacterium*, *Staphylococcus*, *Corynebacterium*) are usable only under conditions, and 42 people were too few to judge their discriminative power (about 65 per group would be needed).
> The fungus *Malassezia* was the only candidate with a discrimination signal (AUC 0.153, q = 0.0003; less abundant on sensitive skin), but it cannot be separated from overall fungal diversity, so absolute quantification is required.
> We turned this screening into a two-stage service: (1) verdicts on a client's existing 16S/ITS data, (2) monitoring only the selected targets by panel sequencing with absolute quantification.
> This is not a diagnostic test. The documents are in Korean; the full evidence is in [`판정표_상세.md`](판정표_상세.md).

## 한 문장으로

민감피부를 가려낼 피부 미생물 지표를 **새로 찾기 전에**, 이미 후보로 거론되는 균이 **패널에 넣어도 되는 균인지부터** 공개 시퀀싱 자료로 심사했고, 그 심사 과정을 기업 R&D 를 위한 **분석 서비스**로 설계했습니다.

## 왜 이 문제인가

- **민감피부에는 진단 표준이 없습니다.** 국제 정의(IFSI 2017)로는 질환이 아니라 *"보통은 자극이 되지 않는 자극에 불편감을 일으키는 증후군"*이고, 지금 쓰는 도구는 설문 · 경피수분손실(TEWL) · 자통시험입니다. 설문 기준으로 여성의 50–60%가 해당합니다.
- **그래서 객관적 지표가 필요하고, 피부 미생물이 후보로 거론됩니다.** 다만 주류 기전 종설에는 미생물이 등장하지 않습니다 — 우리 접근의 약점이면서, 지표 후보를 **제대로 심사하는 일 자체**에 값이 있다는 뜻이기도 합니다.
- **마이크로바이옴 자료에는 고유한 함정이 있습니다.** 비율의 합이 1로 묶여 있고(조성 효과), 얕게 읽으면 있는 균도 0이 되며(시퀀싱 심도), 분류 이름표가 틀리기도 하고, 균이 시료가 아니라 시약에서 오기도 하며(키트 오염), 채취 방법이 결과를 좌우합니다. 유의한 차이 하나만 보고 패널에 넣으면 이 함정에 빠집니다.

## 무엇을 했나

**자료** — 모두 공개 자료의 재분석입니다. 새로 수집한 시료는 없습니다.

| 자료 | 무엇 | 쓰는 곳 |
|---|---|---|
| 한국인 여성 **595명** | 얼굴 세척액 · 16S V3–V4 · 공개 코호트(EGA `EGAS00001007334`)에서 20–79세 여성을 추린 분석 집합 | 사용 조건 (① ② ③ ⑤) |
| 민감 / 비민감 **42명** | 볼 면봉 · 16S V4–V5 + 진균 ITS1 · Keum 2020 (*Microorganisms*) | 판별력 (④) |
| 다른 공개 코호트 | 건강 · 노화 · 계절 · 화장품 · 두피 | 진균 ① ② 확인 · 반복측정 · 다른 자료에서도 판정되는지 |

**심사 — 다섯 관문**

| 관문 | 묻는 것 |
|---|---|
| ① 검출 | 거의 모든 사람에게서 안정적으로 잡히는가 (얕게 읽은 시료에서 사라지지 않는가) |
| ② 교란 | 나이 같은 다른 요인이나 비율 계산 방식 때문에 생긴 차이가 아닌가 |
| ③ 분류 | 이름표(분류 라벨)를 믿을 수 있는가 |
| ④ 판별력 | 민감군과 비민감군을 가르는가 (AUC) |
| ⑤ 방향성 | 종 수준까지 내려가 어느 종의 신호인지 말할 수 있는가 |
| ⑥ 반복측정 *(참고)* | 같은 사람을 다시 재면 같은 값이 나오는가 (ICC) — 판정에는 넣지 않음 |

후보는 807개 속에서 **민감/비민감 결과를 쓰지 않는 규칙**(검출률 · 중앙값 · 두 자료 간 배수)으로 세균 3속을 골랐고, 진균 *Malassezia* 를 더했습니다. 이 규칙은 결과를 본 뒤 글로 정리한 **사후 규칙**입니다.

**분석** — Python 표준 라이브러리만 쓰는 스크립트 13개, 난수 시드 고정. 다시 실행하면 같은 결과가 나옵니다(2026-10-07 재실행 확인).

## 결과

| 후보 | 판정 | 이유 |
|---|---|---|
| *Cutibacterium* | **조건부** | 나이와 얽혀 있어 나이 · 피지 보정이 필수. ④ 판별력은 42명으로 판단할 수 없음 |
| *Staphylococcus* | **조건부** | ② 교란 판정이 비율 계산 방식에 따라 부호가 뒤집힘. 16S 로는 종을 가를 수 없음 |
| *Corynebacterium* | **조건부** | 시약 오염균 목록에도 있는 균이라 최소 read 조건이 필요 |
| ***Malassezia*** (진균) | **후속 패널 검증 우선** | 유일하게 ④ 판별력 신호 — 민감군에서 적음 (AUC 0.153 [0.05–0.29], q=0.0003). 단 진균 다양성과 떼어 볼 수 없음 (ρ=−0.979) |

- **네 후보 모두 반복측정 일치도가 낮습니다**(ICC<0.5) — 한 번 재서 패널 판정을 내릴 수 없습니다(참고 열).
- **「진균이 제일 낫다」가 아닙니다.** 세균은 사용 조건을 알고 판별력을 모르고, *Malassezia* 는 판별력 신호가 있고 사용 조건을 모릅니다. 그래서 다음에 할 일이 다릅니다.
- **유의성만으로는 후보를 정할 수 없습니다.** *Lactobacillus* 는 42명에서 민감군에 많지만(원 논문 보고와 같은 방향), 595명에서는 드물고 시약 오염 신호를 냅니다 — 패널 후보에서 빠졌습니다.
- *Malassezia* 감소는 **원 논문(Keum 2020)이 먼저 보고**한 것과 같은 방향입니다. 우리 기여는 새 발견이 아니라 **패널 적격성 판정**입니다.

## 최종형태 — 패널 시퀀싱 분석 서비스

심사 방법을 기업 R&D 가 쓸 수 있는 **두 단계 서비스**로 설계했습니다. 중간발표의 「심사 도구」와 멘토링 자료의 「검증 설계서」가 각각 1단계 · 2단계의 부품이 됐습니다.

| | 1단계 · 판정 | 2단계 · 패널 감시 |
|---|---|---|
| 고객 | 민감피부 지표(패널)를 개발하려는 기업 R&D | 같은 고객 |
| 입력 | 고객이 가진 16S · ITS 시퀀싱 자료 + 메타데이터 (판별력에는 민감/비민감 라벨, 종 수준에는 ASV 표) | 고객 시료 (채취 프로토콜은 우리가 지정) |
| 처리 | 다섯 관문 파이프라인 | 판정표가 고른 **표적만** 패널 시퀀싱 + **절대량** 측정 |
| 출력 | 판정표 · 후보 카드 · 패널 구성안(넣을 균 · 뺄 균 · 근거) · 측정 설계 | 지표 추적 리포트 (절대량 + 비율) |
| 비용 논리 | 측정비 없이 분석료만 | 판정표가 표적을 줄인 만큼 측정비가 준다 |

**왜 절대량인가** — 패널 시퀀싱도 표적끼리의 「비율」 자료라, *Malassezia* 가 실제로 줄었는지 다른 진균이 늘어 비율만 줄었는지 가르지 못합니다. 그래서 2단계는 절대량을 함께 잽니다.

## 한계

- **진단 도구가 아닙니다.** 어떤 수치도 진단 성능을 입증한 결과가 아니며, 제품 효능이나 치료 효과에 대한 주장이 아닙니다.
- **판별력은 42명 한 코호트에서만** 봤습니다. 신뢰구간 반폭이 ±0.177로 넓고, 작은 표본에서 나온 효과는 부풀려졌을 수 있습니다.
- **42명의 민감 / 비민감 라벨은 원 논문 기준**이라 우리가 재현 · 검증할 수 없습니다. 595명에는 민감 판정이 없습니다.
- **595명은 전원 여성**이라 적용 범위도 여성입니다.
- *Malassezia* 는 피지에 의존해 사는 상재 진균인데, 알려진 기전은 **많을 때**의 이야기라 **「적으면 민감」의 생물학적 해석 근거가 없습니다** — 지표로 쓰더라도 인과 해석은 붙이지 않습니다.
- **패널은 설계안입니다.** 실제 패널로 측정해 검증하지는 않았습니다.

## 다음 단계

- **표본:** 군당 65명이면 AUC 신뢰구간을 ±0.10으로 좁히고, AUC 0.64 이상의 차이를 검정력 80%로 검출합니다. 피부 시료의 증폭 실패까지 생각하면 군당 74명(총 148명)을 모집합니다.
- ***Malassezia*:** 절대 정량(qPCR · 스파이크인)으로 진균 다양성과 떼어 보고, 신호가 몰린 ***M. restricta*** 를 검증 축으로 삼고, 우리 대상에서 반복측정합니다.
- **채취 프로토콜을 먼저 고정합니다** — 채취 부위 · 방법 차이가 판정을 바꿀 수 있기 때문입니다.
