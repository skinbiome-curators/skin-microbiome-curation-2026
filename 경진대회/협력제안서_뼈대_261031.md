## 1. 피부 CRO 에게 (1순위)

### 1-1. 그들의 상황
| 상황 | 근거 |
|---|---|
| 피부 마이크로바이옴 인체 시험을 팔고, 결과물은 16S 균 분류 프로파일(MTP) 분석이다 | ✅ 대한피부과학연구소 운영사 사업보고서 |
| 고객에 대형 브랜드부터 *"인디브랜드사까지"* 있다 | ✅ 같은 보고서 |
| 국내 인체시험 매출은 3년째 줄었고(41.7 → 38.4억 원), 해외 매출은 늘었다(0.07 → 2.13억 원) | ✅ 같은 보고서 |
| 시장의 시험은 대개 무처리 대조가 없어, 결과가 '조건부' 이하로 나오기 쉽다 — 07 은 시점마다 다른 런이라 결론을 못 냈다 | ✅ 결정표 · 07 재분석 |
| 결과를 '말할 수 있는 문장'(국내 · EU · 영국)으로 잇는 상품은 찾지 못했다 | ☐ |

### 1-2. 우리가 주는 것
| 서비스 | CRO 에게의 의미 |
|---|---|
| **① 무료 시험 전 설계 점검 + 낭비 계산** | 중소 고객의 시험 계획을 미리 바로잡아, '돈 내고 결론 없음' 불만을 줄인다 |
| **② '설계 → 시험 → 판정' 묶음** | 우리 설계 요구서가 **그들의 시험 주문**이 된다 · 묶음을 CRO 상품으로 팔 수 있다 |
| **③ 판정 + 바로 쓰는 결과물 세트** | 그들의 균 분류 프로파일 위에 시장별 문장 카드 · 국문 · 영문 문장 후보 · PIF 영문 요약이 붙는다 → 수출 고객에게 파는 시험의 가치가 오른다 |
| **④ 실패 보험** | 결과가 약해도 다음 시험 설계를 무료로 준다 → **다음 시험 주문으로 이어진다** |
| 판정의 성질 | 시험을 하지 않은 쪽의 독립 판정 · 규칙 공개 · 같은 데이터면 같은 결론(입력 지문 · 시드) |

### 1-3. 그들이 얻는 것 (추론 — 확인 전)
- 새 주문(설계 요구서 · 다음 시험) · 수출 고객 대상 상품 강화(해외 매출이 느는 흐름과 맞음)
- 자기 시험을 스스로 판정하지 않아 **독립성**을 내세울 수 있다
- 분석 · 규정 인력을 따로 두지 않아도 된다

### 1-4. 겹치는 위험
한 CRO 는 이미 '균형 유지 여부 평가'를 내세운다(✅ 기사). 그래서 우리는 **CRO 상품에 붙는 모듈**(화이트라벨 또는 공동 상품)로 다가간다 — 경쟁이 아니라 주문을 늘려 주는 쪽.

## 2. 등록 대행사 · EU · 영국 RP 에게 (2순위 — 수출 고객)

| 그들의 문제 | 근거 |
|---|---|
| PIF 에는 효능 증거가 들어가야 한다 | ✅ 1223/2009 제11조 ②(d) *"proof of the effect claimed"* |
| RP 는 PIF 를 당국이 바로 볼 수 있게 비치해야 한다 — 확인은 점검 · 분쟁 때 | ✅ 제11조 ③ *"readily accessible … to the competent authority"* |
| 마이크로바이옴 근거 기준이 비어 있다 · 일반 주장 검토는 원시 데이터 깊이까지 보지 않음 | ✅ 국내 규정 '마이크로바이옴' 0회 · ✅ Biorius *"validation of tests used to substantiate claims"* · 마이크로바이옴 언급 찾지 못함(☐) |

**우리가 주는 것:** ③ 결과물 세트(PIF 영문 근거 요약 1쪽 · 시장별 문장 카드) · 시장 추가(EU → 영국).
**그들이 얻는 것(추론):** 묶음의 차별화 · 점검 대비 · 한국어 CRO 자료를 읽는 부담 감소.

## 3. 협력 방식 (가설)

| 방식 | 내용 | 근거 · 메모 |
|---|---|---|
| **CRO 묶음(②)** | CRO 가 '설계 → 시험 → 판정'을 한 가격으로 판다 · 우리 몫은 새 주문에서 나눔 | 시험 가격은 CRO 가 정함(✅ 영업비밀) · 나눌 의사 ❓ |
| CRO 상품 붙임 | 그들의 시험 결과에 ③ 결과물 세트를 선택 항목으로 | ❓ |
| 등록 묶음 메뉴(2순위) | CPNP · SCPN 묶음에 '마이크로바이옴 근거 점검' 선택 항목 | 학생 팀은 바우처 · 중기부 수행기관이 될 수 없음(✅ 실적 3건 · ✅ᴴ 상근 컨설턴트 2명) → 명의는 그들 · 바우처 컨설팅 몫(한도의 20% ✅ᴴ) 인정 여부는 제도 문의 |

**원가 · 가격 기준:** 우리 원가 약 17.5만–35만 원/건([가정] · `운영모델_261030.md` 5장) · 우리 몫 가정 약 50만 원/건 · 비교: 바우처 컨설팅 몫 최대 80만 원(✅ᴴ 계산) · CPNP 등록 평균 약 258만 원(✅).

## 4. 우리가 하지 않는 것
효능 보증 · 법률 판단 · 등록 · PIF 서명 · 시험 수행. 시험은 CRO, 최종 판단과 서명은 RP 가 한다. 소비자용 인증 마크는 만들지 않는다.

## 5. 남은 일 · 확인할 것
1. **07 견본 한 벌** — ① 설계 점검 + ③ 결과물 세트(국문 · 영문 · PIF 요약)
2. **효능 시험용 표본 수 계산 틀** — 설계 요구서에 필요
3. **제도 문의(B5)** — 2순위 경로의 지원 인정 여부
4. **받는 쪽의 실제 관심** — 발표 뒤 CRO · 등록 기관 1–2곳에 이 제안서로 문의(지금은 가설)
5. **책임 범위 계약 문구** — 판정 문서가 PIF · 광고 근거로 쓰일 때 우리 책임의 범위
