# 협력 제안서 뼈대 — 등록 기관 · RP 에게 (사업 쌓기 B3 · Claude 초안)

**작성:** 2026-10-31 · **대상(이 문서):** 2조 팀원 — 제안서를 다듬을 재료다. **제안서를 받을 쪽(나중):** CPNP · SCPN 등록 묶음을 파는 국내 등록 대행사 · 피부 CRO, EU · 영국 책임자(RP).
**성격:** Claude 초안 · 뼈대. 판매 경로 '등록 기관 묶음 안의 모듈(협력형)'(10/27 장수미 님 임시 결정)을 전제로 한다. **외부에 보내는 것은 발표 뒤**다 — 발표 전 외부 문의는 제도 문의만 하기로 한 의견(재검증 8-9 · 이승민 님)을 따른다. 발표에서는 '협력 제안서 초안'으로 보여 줄 수 있다.
**표기:** ✅ 원문 확인 · ✅ᴴ HWP 원본 글자로 확인 · ☐ 조사 단계 · ❓ 근거 없음 · **추론**

## 1. 받는 쪽의 문제 (그들 입장에서)

| 문제 | 근거 |
|---|---|
| EU · 영국에 내는 제품의 PIF 에는 **효능 증거가 들어가야 한다** | ✅ 1223/2009 제11조 ②(d) *"proof of the effect claimed"* |
| RP 는 PIF 를 **당국이 바로 볼 수 있게** 비치해야 한다 — 확인은 통지 때가 아니라 점검 · 분쟁 때 | ✅ 제11조 ③ *"readily accessible … to the competent authority"* |
| 마이크로바이옴 주장의 **근거 기준이 비어 있다** — 국내 규정 문서에 '마이크로바이옴' 0회 · EU 전용 기준은 찾지 못함 · 영국은 사람 데이터를 기대 | ✅ `../references/광고문장_원문확인_20261026.md` · ☐ · ✅ ASA 지침 |
| 일반 주장 검토는 하지만, **마이크로바이옴 원시 데이터의 함정**(시퀀싱 런 · 배치 · 오염 · 비율 데이터 · 16S 해상도)까지 보는 곳은 찾지 못함 | ✅ Biorius *"validation of tests used to substantiate claims"* · 마이크로바이옴 언급 찾지 못함(☐) |
| 마이크로바이옴 문구를 쓰는 국내 브랜드가 해외 채널에 있다 | ✅ 3곳 재대조 · ☐ 36곳 집계 |

| 단계 | 내용 | 자세히 |

| 0 · 무료 빠른 점검 | FASTQ 머리줄 + 시료표 → 시점과 시퀀싱 런 겹침 · 음성대조 | `운영모델_261030.md` 1장 |
| 1 · 증거 모듈 | 균 표 + 시험 설계 요약 + 쓰려는 문장 → **시장별 문장 카드 + PIF 근거표** | `서비스구성_261027.md` 3–4장 |
| 3 · 시험 설계 요구서 | 데이터가 없거나 부족하면 → 그 문장을 받칠 시험 조건(무처리 대조 · 런 균형 · 기준 시점 두 번 · ITS · 대상 집단) | `운영모델_261030.md` 1 · 4장 |

| 견본 | 07(공개된 국내 화장품 시험) 견본 카드 — 만들 것 | B3 남은 일 |

## 3. 받는 쪽이 얻는 것 (추론 — 확인 전)

| 받는 쪽 | 얻는 것 |
|---|---|
| **등록 대행사** | 묶음의 차별화(마이크로바이옴 주장 근거까지 보는 묶음) · 점검 · 분쟁 때 PIF 근거 대비 · 우리가 분석을 맡아 전문 인력을 따로 두지 않아도 됨 |
| **피부 CRO** | 판정이 '부족'으로 나오면 **시험 설계 요구서가 새 시험 주문으로 이어짐** — 경쟁이 아니라 수주 경로 · 자기 시험을 스스로 판정하지 않아 독립성 확보 |
| **EU · 영국 RP** | 서명 전 마이크로바이옴 근거를 데이터 수준에서 점검받음 · 한국 CRO 자료(한국어 · 국내 형식)를 읽는 부담 감소 |

## 4. 협력 방식 (가설)

| 방식 | 내용 | 근거 · 메모 |
|---|---|---|
| 하청(기본) | 등록 기관이 고객과 계약 · 우리는 모듈을 납품 · 건당 정산 | 학생 팀은 바우처 · 중기부 수행기관이 될 수 없음(✅ 실적 3건 · ✅ᴴ 상근 컨설턴트 2명) → 수행기관 명의는 그들 |
| 묶음 메뉴 | 그들의 CPNP · SCPN 묶음에 '마이크로바이옴 근거 점검' 선택 항목 | 바우처 컨설팅 몫(한도의 20% ✅ᴴ)으로 인정되는지 ❓ — 제도 문의(B5) |
| 수익 배분 | 건당 가격의 일부 | ❓ — 비율은 협의 |

**건당 원가 · 가격 기준:** 원가 약 17.5만–35만 원(가정 · `운영모델_261030.md` 5장) · 비교: 바우처 컨설팅 몫 최대 80만 원(✅ᴴ 계산) · CPNP 등록 평균 약 258만 원(✅).

## 5. 우리가 하지 않는 것
효능 보증 · 법률 판단 · 등록 · PIF 서명 · 시험 수행. 최종 판단과 서명은 RP, 시험은 CRO 가 한다.

## 6. 남은 일 · 확인할 것
1. **07 견본 카드** 만들기(회사명 없이)
2. **제도 문의(B5)** — 모듈이 바우처 · 중기부 지원의 '컨설팅'으로 인정되는지
3. **받는 쪽의 실제 관심** — 발표 뒤 등록 기관 · CRO 1–2곳에 이 제안서로 문의(지금은 가설)
4. **책임 범위 계약 문구** — 판정 문서가 PIF 에 들어갈 때 우리 책임의 범위
5. **B2 결과 반영** — CRO 가 브랜드에 무엇을 넘기는지(보고서만 · 균 표 · FASTQ)에 따라 1단계 입력 조건을 고친다
